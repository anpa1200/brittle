# Open Questions

`OPEN-QUESTIONS.md` שומר שאלות שעדיין לא נכון לפתור. המטרה היא לא לנחש מוקדם מדי.

## Open Questions קיימות

- **OQ-0001:** LLM provider selection for mutation generation.
- **OQ-0002:** rules with no obtainable ground-truth sample.
- **OQ-0003:** האם לכלול vendor-published rules.
- **OQ-0004:** corpus snapshot cutoff date.
- **OQ-0005:** inter-rater reliability protocol for manual mutation review.

## כלל עבודה

כאשר שאלה נפתרת, צריך לעדכן גם `OPEN-QUESTIONS.md` וגם `DECISIONS.md`.
