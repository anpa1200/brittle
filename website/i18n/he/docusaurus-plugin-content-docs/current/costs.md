# יומן עלויות הפרויקט

BrittleBench מוגבל ל-budget קטן. היעד הוא בערך `$350`, עם ceiling של `$500`.

## קטגוריות

- שימוש ב-LLM API
- infrastructure
- רישום domain
- שונות

## למה מתעדים cost

LLM-based studies דורשים שקיפות לגבי computational costs. אם mutation generation
יעלה יותר מהצפוי, זה יכול לשנות sample size, provider choice או number of
mutations per rule. לכן cost הוא methodological constraint, לא רק bookkeeping.

## כלל עבודה

כל expenditure נרשם בזמן אמת. LLM API costs צריכים להירשם לפי phase או run
breakdown כדי שאפשר יהיה לדווח computational costs בפרסום.

אם running total מתקרב ל-`$400`, צריך לפתוח או לעדכן open question לפני שממשיכים
להוציא כסף.
