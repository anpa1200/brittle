# Code of Conduct

הפרויקט משתמש ב-Contributor Covenant v2.1.

העיקרון המרכזי: דיון מקצועי, מכבד, וממוקד ב-research quality, responsible
security work ו-constructive feedback.

## ציפיות מעשיות

- להתמקד ב-evidence וב-methodology.
- להפריד בין ביקורת על rule behavior לבין ביקורת על אנשים.
- לא לפרסם sensitive details או weaponizable payloads.
- לדווח על security issues דרך SECURITY.md ולא ב-public issue.
- לשמור על tone מקצועי גם כשיש disagreement.
