# תרומה לפרויקט

כרגע BrittleBench נמצא ב-research protocol phase ולכן לא מקבל external
contributions למתודולוגיה.

הסיבה היא pre-registration discipline: אם methodology משתנה בעקבות external
feedback לפני lock, קשה להראות שהמחקר לא הותאם בדיעבד לתוצאות או לציפיות.

## מתי תרומות יהיו רלוונטיות

אחרי Phase E, כאשר ה-protocol נעול, contributions יהיו רלוונטיות בעיקר ל:

- פערים ב-corpus
- bugs ב-evaluator
- שיפורי tooling
- feedback על dataset

## מה לא מתאים כרגע

- בקשות להוסיף execution code.
- בקשות להתחיל corpus collection לפני protocol lock.
- שינוי hypotheses או research questions אחרי pre-registration בלי CHANGELOG.
- פרסום raw mutation artifacts או payloads.
