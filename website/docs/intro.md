# BrittleBench

BrittleBench is a research project studying the robustness of publicly
published detection rules against validated, functionally equivalent variants of
the behaviors those rules are intended to detect.

The project is currently in **Phase R1 - Problem Definition**. No
execution-phase code or data should be added until the research protocol is
locked.

## Current Status

- Canonical protocol: [Protocol](/docs/protocol)
- Research plan: [Research Plan](/docs/research-plan)
- Open methodological questions: [Open Questions](/docs/open-questions)
- GitHub task pipeline: [GitHub Project Pipeline](/docs/github-project-pipeline)

## Guardrail

The Docusaurus site is a documentation surface. It does not change the project

results are blocked until `PROTOCOL.md` Section 9.1 reads `LOCKED`.
