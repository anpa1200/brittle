# Results Workspace

This directory is for Phase E4 and Phase A result manifests after protocol lock.

Raw results may contain restricted references or operationally sensitive mutation details. Commit only sanitized outputs, aggregate tables, manifests, and reproducibility-safe artifacts.

Required controls:

- Preserve failure codes separately from true bypasses.
- Record evaluator run IDs, timestamps, version metadata, and detection outcomes.
- Keep confirmatory and exploratory outputs visibly separated.
- Do not publish unsafe per-rule bypass recipes.
